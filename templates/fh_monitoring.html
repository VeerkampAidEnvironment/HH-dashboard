Targets & thresholds

Thresholds are monthly absolute values per reporting unit for the chosen indicator. Targets apply to one calendar month and the exact scope selected. A zero target is allowed; its achievement percentage is unavailable.

Higher is better: below the needs-attention boundary is Critical. Lower is better: above that boundary is Critical. Unit status requires saved thresholds. Reporting columns in the existing FH Excel workbook

Keep the existing workbook, Sheet1 and its first 76 columns. Append headers on row 2 using YYYY-MM | indicator_key, for example 2026-08 | households_visited. Add a new set of columns for each month. Enter whole-number counts on the existing participant rows (starting at row 4). Leave unavailable values blank; enter 0 for a confirmed zero.

Community figures go on the relevant VHT's row (Category = VHT). Care-group figures go on one row for that group and month, not every participant. District, village and unit name identify each report. Optional Health facility and Reporting VHT can be appended as separate columns. Use Reporting VHT to associate group reports entered on a non-VHT participant row with the responsible VHT.

Re-upload through the existing bulk upload. Nonblank monthly values replace matching previously reported values; blank cells retain existing data. Enter 0 to correct a count to zero. Duplicate totals for one unit/month are rejected. Participant attendance retains its existing fill-empty-cells behaviour.
